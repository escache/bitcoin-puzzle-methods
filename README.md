## Disclaimer

This is a historical evidence inventory of methods, runs, and audits performed up to October 2026. Inclusion of a method or run does not constitute independent verification or certification. No private key for Puzzle #71 or any other unsolved puzzle is claimed or disclosed. Corrected or retracted claims supersede earlier stronger statements. GPU claims, balances, and external solve status were not rerun or freshly verified for this compilation.
