# Methods, Drawn

225 monochrome vector diagrams for the existing research inventory.

- METHODS_DRAWN_225.pdf: complete illustrated atlas with category and method bookmarks.
- LINE_ART_PREVIEW.png / .pdf: 12-method contact sheet.
- svg/: one editable vector diagram per method.
- diagram_manifest.json: original method text, sources, findings, visual stages, hashes, and atlas page numbers.
- diagram_specs.tsv: explicit method-to-drawing assignments and labels.
- build_line_art.py: reproducible local renderer.

Marks and weights are schematic. Findings and evidence labels come from methods-with-math.json. The companion preserves that file and the original reports.
